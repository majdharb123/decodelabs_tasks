## Project 1: Task Manager

The first project established the frontend foundation of the task management application.

### Main Features

- Create and organize tasks
- Edit existing task information
- Mark tasks as completed
- Delete tasks
- Store task data in the browser
- Responsive interface for different screen sizes

### Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Browser Local Storage

[View Project 1 Source Code](Project-1-Task-Manager/)

## Project 2: Full-Stack Task Manager

The second project expanded the original frontend concept into a complete full-stack application. Tasks are managed through an Express REST API and stored permanently in PostgreSQL.

### Main Features

- Complete CRUD operations
- Create tasks with descriptions, priorities, and due dates
- Search and filter tasks
- Edit, complete, and delete tasks
- Server-side data validation
- PostgreSQL data persistence
- Responsive desktop and mobile interface
- Deployed frontend, backend, and cloud database

### Technologies

- HTML5, CSS3, and Vanilla JavaScript
- Node.js and Express.js
- PostgreSQL and Neon
- Postman
- Render
- Git and GitHub

- **Live Application:** https://decodelabs-task-manager.onrender.com

## Project 3: ExpenseFlow

ExpenseFlow is a responsive full-stack financial tracking application. It allows users to organize income and expenses, manage categories, filter transactions, and view automatically calculated monthly financial summaries.

### Main Features

- Complete transaction CRUD operations
- Income and expense category management
- Monthly balance, income, and expense summaries
- Spending breakdown by category
- Recent transaction overview
- Search and transaction filters
- Month and year selection
- Server-side validation and database constraints
- Responsive desktop, tablet, and mobile interface
- Data persistence after page refresh
- Fully deployed frontend, backend, and cloud database

### Technologies

- HTML5, CSS3, and Vanilla JavaScript
- Node.js and Express.js
- PostgreSQL and Neon
- Postman
- Render
- Git and GitHub

### Live Links

- **Live Application:** https://expenseflow-app-c2an.onrender.com
- **REST API:** https://expenseflow-api-d8tq.onrender.com
- **Documentation:** [Project 3 README](Project-3-Full-Stack-Expense-Tracker/README.md)
- **Source Code:** [Project 3 Folder](Project-3-Full-Stack-Expense-Tracker/)
